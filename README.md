# Lusor on AndroidWorld

Results and method for Lusor's run of the [AndroidWorld](https://github.com/google-research/android_world) benchmark on 9 November 2026: all 116 tasks, one attempt each.

| Grader | Passed |
| --- | --- |
| Mobilerun's fork of the grader ([droidrun/android-world](https://github.com/droidrun/android-world) `c5467e6`) | **116 / 116** |
| Google's original grader ([google-research/android_world](https://github.com/google-research/android_world) `30583e2`) | **114 / 116** |

Median time per task: 48.2 s. Cost for all 116 tasks: $2.95.

The score is from the Lusor Harness at the build in production on 9 November 2026, with DeepSeek V4.1 Flash (low effort) choosing its actions. The open-source version of the harness is a separate release and has not been benchmarked.

## What's here

| Path | What it is |
| --- | --- |
| [`METHOD.md`](METHOD.md) | How the run was set up, graded, timed and costed, and what the agent had available. |
| [`results.csv`](results.csv) | One row per task: both grader results, time, cost, tool calls, any note, and AndroidWorld's step budget against the run's device actions. |
| [`data/`](data) | For every task, `task.json` (goal, results, final summary, skills opened) and `steps.json` (each step's tool, timing and note), plus `index.json` and `SHA256SUMS`. |
| [`actions/`](actions) | For every task, each step's arguments as the agent sent them (the element tapped, the text typed), matched to `steps.json`. |
| [`skills/`](skills) | The six app skills written for AndroidWorld's test apps, which were in the agent's skill catalog during the run. |
| [`comparison/`](comparison) | How the published figures compare with Mobilerun's, with estimates labelled as estimates, and each task's step budget against the run's action count. |

## Videos

Every task was recorded from start to finish. The videos and posters stay on data.lusor.ai, next to the files in `data/`:

- Results page: [lusor.ai/benchmarks/androidworld](https://lusor.ai/benchmarks/androidworld)
- All 116 tasks, with video: [lusor.ai/benchmarks/androidworld/tasks](https://lusor.ai/benchmarks/androidworld/tasks)
- Raw files: `https://data.lusor.ai/benchmarks/androidworld/2026-11-09/<task>/video.mp4` (also `video.webm` and `poster.webp`)

Each task also has a shorter copy, `video-trimmed.mp4` / `video-trimmed.webm`, that starts 1 second before the agent's first action. `trimmed.json` gives each task's cut (`trim_offset_s`; subtract it from the times in `steps.json`), and `SHA256SUMS-trimmed` lists their checksums. The original videos are unchanged.

`data/` is a copy of the dataset at [data.lusor.ai/benchmarks/androidworld/2026-11-09](https://data.lusor.ai/benchmarks/androidworld/2026-11-09/index.json). To check a file against the published checksums:

```bash
cd data && sha256sum -c --ignore-missing SHA256SUMS
```

## About leaderboard figures

AndroidWorld results, including these, are reported by the team that ran them. The AndroidWorld community leaderboard does not verify entries. Every task is published so this run can be checked.

<sub>AndroidWorld sets a step budget for each task. This run did not enforce it; 22 of the 116 tasks used more device actions than their budget. Mobilerun's published run stayed within it on every task. See <a href="METHOD.md#tasks-and-environment">METHOD.md</a>.</sub>
