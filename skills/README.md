# AndroidWorld app skills

These six skills (Markor, Broccoli, Simple Calendar, Tasks, OsmAnd and Camera) were written for the test apps of the AndroidWorld benchmark. They were in the agent's skill catalog during the 9 November 2026 run; the agent opened a skill when its description matched the task.

Some rules follow how the benchmark phrases and grades its tasks rather than what an everyday user would want. For example, Markor notes are saved without a file extension unless the task names one, and the Camera skill covers the emulator's AOSP Camera2 app, not the camera apps on most phones. They are published as part of the run's record, not as general-purpose skills.

Each skill is a `SKILL.md` file in the [Agent Skills](https://agentskills.io) format. Lusor's maintained app skills are in [lusor-ai/lusor](https://github.com/lusor-ai/lusor/tree/main/skills).
